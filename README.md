# Наш белый лист

Романтический холст: кисть, ластик, сердца, текст, смайлики.

Откройте `index.html` в браузере на телефоне или компьютере.

Это личный лист на устройстве. Чтобы рисовать вдвоём на одном листе в реальном времени, откройте https://excalidraw.com , нажмите «Share» и отправьте ссылку второй половинке.

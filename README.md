# Наш белый лист

Романтический холст: кисть, ластик, сердца, текст, смайлики.

## Постоянная ссылка

Файл уже в этом репозитории. Чтобы ссылка заработала в браузере:

1. Открой https://github.com/kubamakc27-byte/love-canvas/settings/pages
2. Build and deployment → Source: Deploy from a branch
3. Branch: main, folder: / (root) → Save
4. Через 1–2 минуты откроется https://kubamakc27-byte.github.io/love-canvas/

Это личный лист на устройстве: рисунок не уходит на телефон второй половинки сам.

## Чтобы рисовать вдвоём на одном листе

Открой https://excalidraw.com , нажми Share → Live collaboration и отправь ссылку.
Или https://cnvs.app — без регистрации, ссылка общая сразу.
